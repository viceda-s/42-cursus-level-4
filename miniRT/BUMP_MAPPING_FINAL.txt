🔧 TECHNICAL IMPLEMENTATION:

Algorithm:
  1. Parse bump parameters from .rt file
  2. During rendering, for each ray-object intersection:
     a. Calculate geometric normal
     b. If object has bump mapping:
        - Build TBN (Tangent-Bitangent-Normal) basis
        - Calculate UV coordinates (spherical/planar mapping)
        - Sample height function: h(u,v) = 0.5 + 0.5*sin(2πu)*sin(2πv)
        - Compute height gradients (dh/du, dh/dv)
        - Perturb normal in tangent space
        - Transform to world space
     c. Use perturbed normal for Phong shading

Supported Objects:
  - Sphere: ✓ Full support (spherical UV)
  - Plane:  ✓ Full support (planar projection)
  - Cylinder: ⚠️ Parsing only (uses geometric normal)

🎨 VISUAL EFFECT:

The bump mapping creates:
  • Surface texture illusion through lighting
  • Dynamic highlights and shadows
  • Wavy procedural pattern
  • Smooth silhouette (no geometry change)
  • Best results with directional lighting

Parameters:
  • strength: Controls bump intensity (0.5=subtle, 2.0=strong)
  • buv (UV scale): Controls pattern frequency (higher=smaller pattern)

💡 TIPS:

1. Use bump=1.0 to 2.0 for realistic effects
2. Higher buv values (3.0, 4.0) create finer detail
3. Combine with checkerboard for interesting patterns
4. Strong directional lighting shows bumps best
5. Comments in .rt files are supported (lines starting with #)
