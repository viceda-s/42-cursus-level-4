🎨 PARAMETER GUIDE:

  bump          → Enable with defaults (strength=1.0, uv=1.0,1.0)
  bump=X        → X controls intensity (0.5=subtle, 3.0=pronounced)
  buv=U,V       → UV tiling (higher=more repetitions)

  Examples:
    bump=0.5      → Very subtle bumps
    bump=1.0      → Normal bumps (default)
    bump=2.0      → Strong bumps
    buv=1.0,1.0   → Original pattern size
    buv=4.0,4.0   → 4x more repetitions (smaller pattern)

🔧 TECHNICAL NOTES:

  • Uses procedural height function: 0.5 + 0.5*sin(2πu)*sin(2πv)
  • TBN (Tangent-Bitangent-Normal) basis for coordinate transformation
  • Normal perturbation applied BEFORE Phong shading
  • Works with: Spheres ✓, Planes ✓, Cylinders (parsing only)
  • No external textures needed (fully procedural)

💡 COMBINING WITH CHECKERBOARD:

  Yes! You can use both:
    sp 0,0,0 10 255,0,0 checker bump=1.5

  The checkerboard affects color, bump affects lighting.
